# Notion 风格本地数据库工作台重做

## 目标与用户确认的范围

将 ChatObsidian 重做为 React + Vite + Tauri 的本地知识工作台，重点是应用图标、Notion 风格界面与画廊数据库；移除无用工具箱，保留快速弹窗、单量和增量打开。用户进一步明确要求实际查看 Notion 官方应用内部截图，不能只参考营销页。重写 README 和根 AGENTS，并检查危险的文件与窗口操作。

## 研究与产品变化

- 实际查看 Notion 官方 Reading List 画廊、Book Tracker 看板、侧栏、Engineering tasks 视图菜单、GreenWave 页面布局、Design wiki 和 Company wiki 截图。来源和观察记录于 `docs/notion-research.md`，中间参考图片放在 Git 忽略目录，不作为产品素材分发。
- 采用白色/暖灰表面、细边框、蓝色新建按钮、紧凑属性标签与页面式标题；提供浅色、深色、系统主题。使用原创黑白书页 C 图标，重新生成 Tauri 图标；移除紫色样式。
- 仓库成为数据库页面；增加独立页面、自定义数据库和六类属性（文本、数字、单选、日期、复选框、链接）。画廊、表格、状态看板共享记录，支持新建命名视图，按视图保存搜索、筛选、排序、预览、卡片大小与可见字段。
- 增加本地图片封面、填充/完整显示、正文编辑、收藏、归档/恢复和 JSON 工作台导出。看板拖动变更状态；页面状态选择框提供键盘替代操作。
- 保留快速弹窗的仓库/笔记标题检索、类型筛选、键盘选择、实时刷新，以及托盘、单实例和可选开机自启。
- 删除工具箱、配置同步、模板覆盖及强制结束 Obsidian 的 UI、IPC 和后端执行实现；保留旧设置兼容字段、历史数据表及磁盘备份。

## 数据与窗口操作边界

- 新增 `workspace.rs`，SQLite 追加 collection/item/view 表；旧库迁移前用 `VACUUM INTO` 创建一致性快照。只有真实启动旧库时才执行实际迁移，本次兼容验证使用临时副本。
- 保存采用事务、外键与 revision 检查；拒绝通过遗漏记录删除已有数据或重新绑定仓库。前端串行保存，失败不更新提交态，页面编辑草稿保留。归档不删除文件。
- 上传封面只接受受限 PNG/JPEG/WebP；前端缩小，Rust 核验内容/尺寸；拒绝 SVG、远程地址和任意文件路径。工作台总载荷设上限。JSON 导出不能覆盖应用数据目录或登记仓库。
- 扫描/索引不写入 Obsidian 文件。URI 打开使用已登记的 Vault ID，关闭窗口前核对最新登记路径；笔记必须已存在、为 Markdown 且规范化后位于仓库内部。
- 识别 Obsidian 窗口时验证进程映像与标题，关闭前重新核对；名称/归属有歧义时停止。跨 WebView 打开互斥，正常关闭等待最多 15 秒，超时停止；删除强杀后门。
- 设置使用原子替换；无法读取或损坏的现有设置不被默认值覆盖。快捷键/开机自启设置失败回滚，保存队列跨组件卸载继续保持顺序。删除已不再使用的快捷键录制 IPC。

## 遗留边界与后续方向

- 真实跨虚拟桌面的关闭/重开、不同 Obsidian 插件和未保存对话框组合仍需在专门准备的测试仓库中人工验收；没有用用户正在编辑的窗口执行破坏性测试。
- 当前正文为纯文本；没有 Notion 公式、关系/汇总、块编辑、多人协作、远程同步或 JSON 导入。支持归档，不提供永久删除与视图删除。
- 含 `#`、`^` 的笔记路径与 Obsidian URI 标题/块定位有歧义，当前拒绝从弹窗打开；未登记文件夹需先在 Obsidian 打开并重新扫描。
- 旧 active 架构与同步知识页可能与本次实现不一致；根 AGENTS 明确要求核对当前代码、README 和最新日志，不恢复被移除的能力。前次架构快照见 [[日志/2026-09-16-工程架构审查]]。
