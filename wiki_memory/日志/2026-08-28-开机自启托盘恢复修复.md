# 开机自启托盘恢复修复

## 目标

修复 Windows 开机自启后托盘图标存在，但点击托盘或再次启动程序不能可靠恢复仓库中心的问题。

## 根因

开机自启使用 `chat-obsidian.exe --background`，主窗口按设计保持隐藏。Tauri 单实例插件在第二次启动时通过同步 `WM_COPYDATA` 调用回调；回调原本直接执行虚拟桌面和 WebView 窗口恢复。任何窗口 API 等待都会阻塞这条同步消息，使后台进程表现为托盘仍在但恢复请求无响应，第二次启动也可能悬挂。

## 决策与实现

- 单实例、托盘左键、托盘菜单和“显示仓库中心”快捷键统一将恢复任务投递到 Tauri 主线程，立即返回同步单实例消息。
- 主窗口恢复后执行显示、取消最小化、请求焦点，并在 Windows 上补充还原、置顶和前台激活。
- 虚拟桌面切换失败不再静默丢弃，写入标准错误日志；窗口恢复或任务投递失败同样记录原因。
- 不改变 `--background` 的静默启动语义，不自动显示主窗口，也不结束 Obsidian。
