# 开发验证流程

常规顺序：

1. 读取 wiki_memory/AGENTS.md 和当前状态页面。
2. 修改前端时运行 corepack pnpm typecheck 和 corepack pnpm test。
3. 修改桌面行为时补充或运行 Playwright、Rust 单元测试。
4. 运行 python wiki_memory/工具/memory_lint.py index 和 check。
5. 完成实质任务后追加日志，记录变更、测试、遗留问题和待确认长期记忆。

发布前再执行 release 构建和 NSIS 打包，并核对外部 Python 脚本哈希。
