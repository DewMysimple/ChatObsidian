# 工具箱

工具箱使用固定脚本定义，不接受任意路径或任意命令。preview_script_run 会返回绝对脚本路径、Python 路径和版本、工作目录、终端、日志目录、交互性和问题列表。

确认后才调用 run_script。运行记录保存脚本、解释器、工作目录、退出状态和日志位置。PowerShell 5.1 兼容依赖 UTF-8 BOM 包装器和 Set-Location -LiteralPath。
