# 前后端接口

前端和 Rust 通过稳定的 camelCase 数据契约通信，核心类型包括 VaultRecord、VaultGroup、NoteIndexEntry、QuickSwitcherRefresh、SyncCategory、ConfigDiff、SyncPlan、BackupManifest、OperationRecord、ScriptRunPreview 和 AppPreferences。

核心 command 包括仓库扫描、快速切换刷新、目录更新、仓库或笔记打开、标题搜索、差异计算、同步、回滚、脚本预检与运行、偏好保存和快捷切换器控制。新增 command 必须同时更新 TypeScript bridge、Rust handler、mock 和测试。
