# 同步中心

同步中心通过 SyncPlan 描述来源、目标、类别、插件设置和完整镜像确认。Rust 后端生成 ConfigDiff，对 JSON 做结构化键路径差异，并对疑似密钥、令牌字段脱敏。

执行同步前必须先完成所有目标备份。日常同步不删除目标额外文件；删除和工作区同步必须二次确认。操作记录包含状态、日志和可回滚标记。
