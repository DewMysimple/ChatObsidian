# 窗口与快捷键

Tauri 主窗口和快速切换窗口均默认隐藏，由托盘、快捷键或单实例事件恢复。恢复请求统一投递到 Tauri 主线程；单实例插件收到第二次启动的同步 WM_COPYDATA 消息时不会在消息回调里直接执行窗口/虚拟桌面操作，避免后台进程被阻塞而出现托盘图标但无法打开。Windows 恢复还会执行还原、置顶和前台激活。快捷键捕获期间先暂停旧注册，保存失败时重新注册原绑定。

快速切换窗口每次显示都会刷新；窗口可见时每秒更新真实 Obsidian 窗口状态、每 5 秒刷新笔记标题索引，失焦或隐藏后停止轮询。仓库结果优先置顶真实打开项，再按最近打开时间排序；仓库/笔记筛选开关使用本地 WebView 存储记住上次选择，首次默认为全部开启。仓库筛选按钮显示当前可用仓库数量。

Windows 后端使用窗口标题、Vault ID、窗口句柄和当前虚拟桌面确定安全操作范围。跨桌面重开只做正常关闭和普通 URI 打开，不调用未公开虚拟桌面移动接口。
