# 窗口与快捷键

Tauri 主窗口和快速切换窗口均默认隐藏，由托盘、快捷键或单实例事件恢复。快捷键捕获期间先暂停旧注册，保存失败时重新注册原绑定。

Windows 后端使用窗口标题、Vault ID、窗口句柄和当前虚拟桌面确定安全操作范围。跨桌面重开只做正常关闭和普通 URI 打开，不调用未公开虚拟桌面移动接口。
