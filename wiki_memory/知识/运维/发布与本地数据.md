# 发布与本地数据

应用数据位置：

- %APPDATA%\ChatObsidian\settings.json
- %LOCALAPPDATA%\ChatObsidian\catalog.sqlite
- %LOCALAPPDATA%\ChatObsidian\backups
- %LOCALAPPDATA%\ChatObsidian\logs
- %LOCALAPPDATA%\ChatObsidian\runtime

项目代码或配置迭代默认递增 patch 版本，并保持 `package.json`、`src-tauri/Cargo.toml` 和 `src-tauri/tauri.conf.json` 三处版本一致。发布使用 `build-installer.ps1`：构建前只处理 `chat-obsidian.exe`，验证通过后覆盖 `src-tauri/target/release/chat-obsidian.exe`，保留带版本号的 NSIS 包并覆盖 `src-tauri/target/release/bundle/nsis/ChatObsidian-latest-setup.exe`。

检测到已有安装时，脚本自动运行固定安装包进行覆盖升级；NSIS 的 `NSIS_HOOK_PREINSTALL` 会在复制新文件前结束 ChatObsidian 并确认进程消失。无法结束进程、文件仍被占用或安装返回非零退出码时立即中止。任何步骤都不得结束 `Obsidian.exe`。

升级只覆盖程序文件和资源，保留 `%APPDATA%\ChatObsidian`、`%LOCALAPPDATA%\ChatObsidian` 下的设置、目录、数据库、日志、备份和运行时数据。构建输出位于 `src-tauri/target/`，不纳入 Git；完成代码/配置迭代后仍需更新记忆、提交并推送 `origin/main`。
