# 已知问题与性能边界

- 差异计算即使放在后台线程，也会受到仓库数量、插件文件数量和磁盘 I/O 影响；前端必须保留加载态、错误态和恢复入口。
- 打开仓库的最终速度由 Obsidian 自身启动、插件加载和 Windows 桌面切换决定，不能承诺所有场景达到毫秒级。
- 正常关闭被插件阻止或超过等待时间时，不得自动强杀，也不得发送新的打开 URI；用户必须明确选择重试或强制结束整个 Obsidian 进程。
- 同名仓库在没有稳定 Obsidian ID 或可靠路径匹配时不能自动关闭，防止误关。
- 本记忆目录记录已观察到的边界，不替代实际代码、日志和用户数据。
