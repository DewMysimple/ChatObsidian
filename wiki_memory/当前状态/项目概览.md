# ChatObsidian 项目概览

## 一句话结论

ChatObsidian 是面向 Windows 11 x64 个人用户的本地 Obsidian 多仓库管理桌面应用，当前代码版本为 0.1.10。

## 当前能力

- 仓库中心：合并 Obsidian 注册表和扫描根目录，按稳定 Vault ID 去重，支持显示名、分组、标签、收藏、隐藏、归档和拖拽排序。
- 快速切换：真实打开仓库优先，再按最近打开时间排序；搜索仓库、分组、标签和笔记标题；支持仓库/笔记开关、类型徽标、真实窗口打开状态和三个全局快捷键，并显示可用仓库数量。
- 浮窗可见时每秒刷新仓库状态，每 5 秒刷新笔记标题索引；搜索开关记住上次选择。
- 跨桌面打开：单量打开和增量打开会正常关闭目标窗口后在当前桌面重开；Obsidian 原生策略不干预。
- 同步中心：以全局模板和仓库例外为基础，提供差异、增量备份、同步、回滚和配置变化提示。
- 工具箱：固定允许列表中的 9 个 Python 脚本，运行前预检和确认，通过 UTF-8 BOM PowerShell 包装器执行。
- 托盘与启动：单实例、关闭到托盘、左键恢复、开机自启和静默后台启动。
- 发布覆盖：代码或配置迭代默认递增 patch；发布脚本覆盖固定 release exe 和 `ChatObsidian-latest-setup.exe`，检测到已有安装时自动覆盖升级并保留应用数据。

## 技术与版本

- 前端：React 19、TypeScript、Vite、Zustand、原生 CSS、Radix UI 和 Phosphor Icons。
- 桌面层：Tauri 2。
- 后端：Rust 2024，SQLite（bundled rusqlite）。
- Windows 能力：Windows 虚拟桌面识别、全局快捷键、托盘、Obsidian URI、PowerShell 和 NSIS。
- 浏览器演示模式：前端通过 src/lib/desktop.ts 使用 mock 数据，不访问本地文件。
