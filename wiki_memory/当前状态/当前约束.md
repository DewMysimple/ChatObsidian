# 当前约束

- 首版只支持 Windows 11 x64，不依赖网络服务。
- 不移动、重命名、删除或写入现有 Obsidian 仓库，除非用户明确执行同步或配置采纳操作。
- C:\Users\Administrator\Desktop\Obsidian仓库 下的 9 个 Python 工具脚本保持只读。
- 日常同步不删除目标仓库额外文件；完整镜像和工作区同步必须二次确认。
- 同步写入前必须为所有目标创建增量备份；失败时停止后续目标并保留可回滚入口。
- 前端只能通过已登记仓库和应用数据目录访问本地路径。
- 内部保留 Windows 长路径前缀，用户界面统一隐藏 \\?\。
- 偏好设置自动保存；快捷键和开机自启变更必须保持事务式回滚。
- 关闭主窗口默认隐藏到托盘，不创建除开机自启以外的后台服务。
