# ADR-002｜仓库身份与重命名处理

## 状态

active

## 决策

优先使用稳定的 Obsidian Vault ID 识别仓库；同时以规范化绝对路径去重。目录名变化时，只有未设置自定义显示名的记录才跟随新目录名；用户明确设置的显示名和分组保持不变。

## 理由

- 目录路径会改变，Obsidian ID 更适合作为长期身份。
- 用户自定义名称不能被扫描覆盖。
- 数据库只更新登记元数据，不删除无法匹配的旧记录。

## 验证方式

使用中文、空格、超长路径和目录重命名场景验证无重复导入、显示名跟随和自定义名保留。
