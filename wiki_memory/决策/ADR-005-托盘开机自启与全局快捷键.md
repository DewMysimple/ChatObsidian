# ADR-005｜托盘、开机自启与全局快捷键

## 状态

active

## 决策

开机自启由偏好设置控制，默认关闭；启用后使用 Tauri 官方 autostart 插件以 --background 静默驻留托盘。主窗口关闭默认隐藏到托盘，托盘左键恢复并聚焦主窗口。

全局快捷键默认如下：

- Ctrl+Alt+O：显示仓库中心
- Ctrl+Alt+1：单量打开
- Ctrl+Alt+2：增量打开

快捷键和开机自启变更采用事务式保存，注册或写入失败时恢复旧状态。
