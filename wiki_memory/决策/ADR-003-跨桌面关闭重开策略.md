# ADR-003｜跨桌面关闭重开策略

## 状态

active

## 决策

当目标仓库只在其他 Windows 桌面打开时，先正常关闭相关窗口，再通过普通 Obsidian Vault URI 在当前桌面重开。单量模式关闭全部仓库，增量模式只关闭目标仓库，Obsidian 原生模式不干预。

## 安全边界

- 每 50ms 检查一次关闭状态，最多等待 15 秒。
- 超时不自动强杀、不发送打开 URI。
- 用户明确选择强制处理时才结束整个 Obsidian 进程。
- 不移动外部窗口，也不使用 paneType=window。
