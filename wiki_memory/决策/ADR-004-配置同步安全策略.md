# ADR-004｜配置同步安全策略

## 状态

active

## 决策

采用“全局模板 + 仓库例外”模型。日常同步只新增或覆盖选中项目，不删除目标额外文件；完整镜像、删除和工作区同步必须单独确认。

## 写入顺序

1. 计算结构化差异和预计备份大小。
2. 为所有目标创建增量备份。
3. 按目标顺序应用，任一目标失败则停止后续写入。
4. 保存操作记录并提供一键回滚。

配置快照用于仓库关闭后的变化检测，工作区文件和未启用插件设置默认排除。
