# ADR-001｜桌面应用技术栈

## 状态

active

## 决策

使用 Tauri 2 + Rust 作为桌面和危险能力层，使用 React + TypeScript + Vite + 原生 CSS 作为 UI 层。

## 理由

- 前端易于维护和修改，适合 WhisperUI 风格的网页技术 UI。
- Rust 可以集中执行路径校验、备份、窗口、进程和同步等高风险操作。
- Tauri 的 Windows 打包和托盘能力满足本地单机应用需求。

## 影响

- 需要同时维护 Node/pnpm 和 Rust 工具链。
- 浏览器演示模式必须继续维护 mock 桥接。
